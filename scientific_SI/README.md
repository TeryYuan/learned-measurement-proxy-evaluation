# Saved scientific attachments

The [reader index](../source_index.tsv) is the current file-level manuscript crosswalk and rights/access inventory. This collection supplies 140 original scientific table files, seven chemical-coverage files and three scaffold-stratified source files, plus [naming_map.csv](../naming_map.csv). The 140 include all 17 S24 files, eight S25_ALT files, four S26_seed files and formal S40/S41 tables. Prefixes are historical filenames: S24 files support SI S10/S13, S25_ALT supports SI S14/Table S25, and S26_seed supports SI S15/Table S26; they are not clinical section numbers.

The seven formerly author-review numeric tables are now in tables/ as scientific attachments, including NAM_DILI_overlap_by_split.csv. No author-review directory or private commentary is exported here. S40 distribution quantiles and query/reference nearest-neighbor records accompany the table. S41 has the six formal stratum rows, an eight-row full-precision source table (two overall rows do not replace formal overall intervals), 373 saved member/score rows and original analysis metadata. Empty strata each have one positive; the saved conditional intervals do not represent variation in positive compounds. They remain in the CSV; the manuscript table continues to show dashes for them.

The [recovery record](RECOVERY_RECORD.json) reports checks of all 154 recovery inputs against the original project or preceding candidate: 129 exact byte copies and 25 exact-token column projections. Of these, 151 files are newly delivered here or as the naming map; the existing minimal-replay group sidecar is reused, and two historical indexes are retained only in the separate author handoff. [Column rules](COLUMN_TREATMENT.json) retain every listed numeric/label/score/fold token and row order. No scientific value was recomputed or altered.

Fourteen tables contain unresolved group mappings, explicitly listed in [the local recovery requirements](LOCAL_RECOVERY_REQUIREMENTS.json). Only exact old-string matches to previously established anchors were mapped. An empty anchor with source_empty differs from group_mapping_unresolved. recovery_source_row is a source row address, not a new chemical identity. Unmapped cells cannot be treated as one group, one new group per row, or silently dropped. The S23 group_code mapping is confined to its own verified member namespace and cannot be generalized to other modules.

The attachments support inspection of saved evidence. The earlier 238-check replay covers only the minimal N/BSEP/C/ALT24/bridge collection; it does not certify S24/S25/S26/S40/S41. Complete liver training, chemical reconstruction from structures, and all extended grouped resampling are outside this delivery's validated scope. Chemical strings, raw third-party workbooks, training caches and fitted objects are omitted. Group-dependent extensions require actual missing mappings; this task did not invent them or rerun training/resampling.

The author grants and retained source conditions are specified in [FILE_LICENSES.json](../FILE_LICENSES.json), [license scope](../LICENSE_SCOPE.md) and [third-party notices](../THIRD_PARTY_NOTICES.md). The recovery record describes its original stage; current release state is in RELEASE_STATUS.json at the repository root.
