# Data conditions

The exact author grant and retained source conditions for each file appear in [FILE_LICENSES.json](../FILE_LICENSES.json). The narrative scope is in [LICENSE_SCOPE.md](../LICENSE_SCOPE.md), with [third-party attribution](../THIRD_PARTY_NOTICES.md), [22 replay input decisions](REPLAY_INPUT_DECISIONS.csv), [excluded-field decisions](REPLAY_EXCLUDED_FIELDS.csv), [Hallmark source record](Hallmark_source_and_license.txt), and [NHANES source notes](../NHANES_Q3_Project/sources/SOURCES.md).

FDA source facts, SI002/SI004 source labels and covered adaptations, TG-GATEs measurement-derived material, author scores and author metadata are distinguished. The MIT software grant does not license data. No original raw workbooks/CEL/GMT files, NHANES participant-level data, enriched structure caches or fitted model objects are included.

The [reader index](../source_index.tsv) maps delivered scientific evidence to the manuscript. [RECOVERY_RECORD.json](../scientific_SI/RECOVERY_RECORD.json) records retained and omitted fields and their earlier recovery checks. Its historical preparation status is preserved; the current author grants are in FILE_LICENSES.json. Missing grouping relationships remain explicitly documented and have not been invented.
